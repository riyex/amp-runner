# Security

## Supported versions

Before the first versioned release, only the latest code on `main` receives security
updates. A version support table will be added when releases exist.

## Reporting a vulnerability

Do not open a public issue for a vulnerability, exposed credential, or report that could
help someone exploit another user's machine. Use **Report a vulnerability** in the
repository's Security tab to send a private report through GitHub.

Include the affected revision, macOS version, impact, reproduction steps, and any proposed
mitigation. Please allow time for investigation before publishing details. This
single-maintainer project does not promise a response or resolution deadline.

Use ordinary GitHub Issues for non-sensitive bugs, privacy questions, and hardening ideas
that do not describe an exploitable weakness.
